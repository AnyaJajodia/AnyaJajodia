<h1 align="left">Hi, I'm Anya.</h1>

**I build things at the intersection of software, research, and a little curiosity.**

I'm a Computer Science student at Barnard College, Columbia University, interested in thoughtful software, applied AI, and the ways technology can help people investigate, create, and connect ideas.

These days, my work moves between engineering products, building AI-powered tools, and supporting natural-history research. I like projects that require learning an unfamiliar domain, asking good questions, and turning a messy problem into something people can actually use.
